# Khelo — Sports Landing Page

A multi-sport landing page built with Next.js, TypeScript, and Tailwind CSS.

## Sections

- **Home** — Hero with football imagery, brand stamp, and social links
- **Matches** — Upcoming match countdown + multi-sport fixture cards (football, cricket, basketball, tennis)
- **Highlights** — Featured match video with sidebar video list
- **News** — Latest sports news grid
- **About** — About Khelo Sporting Club
- **Stats** — Club statistics (matches, trainers, players, awards)
- **Products** — Top products showcase
- **Footer** — Newsletter signup + background image + social links

## Tech Stack

- Next.js 16 (App Router, Turbopack)
- TypeScript
- Tailwind CSS v4
- Framer Motion
- react-icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
```
